# Neowise: разбор входящих заявок

Нужен Node.js 20+. Зависимости и API-ключи не требуются.

## Запуск

```sh
node server.mjs
```

Открыть http://127.0.0.1:3000.

Другой порт:

```sh
PORT=3001 node server.mjs
```

## Тесты

```sh
npm test
```

Тесты поднимают отдельный сервер на свободном порту и проверяют три темы,
ошибки модели, таймаут и некорректный ввод через HTTP.

## Ручная проверка

Введите обычный текст (например, «Где доставка?») — появятся тема и черновик.
Затем по очереди отправьте `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`,
`[empty-draft]`: страница должна показать сообщение о ручной проверке и убрать
предыдущий черновик. Пустой ввод показывает просьбу ввести текст.

`POST /api/triage` принимает `{"text":"текст заявки"}`. Некорректный JSON или
пустой/нестроковый `text` возвращает HTTP 400 с `status: invalid_input`.
В `handleTriage` проверяются JSON модели, тема (`delivery`, `pricing`, `other`)
и непустой черновик. Ошибка, некорректный ответ или ожидание дольше 300 мс
возвращают HTTP 200 с `status: manual_review`, `topic: null`, `draft: null`.
При таймауте запрос к имитатору отменяется через AbortController.

Используется исходный `mock-ai.mjs`, без внешней AI-модели и реальных данных.
При разработке использовался ChatGPT/Codex.
Менеджер получает тему и заготовку ответа; пользу можно измерить временем
обработки заявки и долей черновиков, принятых без существенных правок.
